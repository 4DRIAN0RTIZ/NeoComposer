Para el dev que vive en la terminal

NeoComposer integra las herramientas que ya usas, sin fricción. Ahora con soporte CLI para automatización.

📝

Neovim como editor

Escribe tu correo con el editor que ya dominas. Atajos, macros, plugins — todo disponible. El archivo temporal se elimina al enviar.

📎

Adjuntos via Yazi

Navega tu sistema de archivos con Yazi para seleccionar adjuntos. Sin escribir rutas completas. Adjunta múltiples archivos.

📋

Agenda de contactos

Guarda destinatarios frecuentes en un JSON. Gestión con flag -a o usa índices con --agenda-index para scripting.

✍️

Firma HTML

Define una firma personalizada en HTML con imágenes, links y estilos. Se inyecta automáticamente en cada correo.

🔐

SMTP + TLS

Conexión segura via STARTTLS. Compatible con Gmail, Outlook y cualquier proveedor SMTP estándar.

⚡

Modo programático

Integra en scripts con --recipient, --subject, --body, --attachments. Automatiza notificaciones y reportes.

// instalación

Listo en 3 pasos

El instalador detecta tu distro, instala dependencias y configura el acceso directo.

bash instalación rápida
# curl
curl -fsSL https://raw.githubusercontent.com/4DRIAN0RTIZ/NeoComposer/main/install_neocomposer.sh | bash

# wget
wget -qO- https://raw.githubusercontent.com/4DRIAN0RTIZ/NeoComposer/main/install_neocomposer.sh | bash
ℹ️

El instalador descarga los archivos directamente desde GitHub. Para instalación manual, clona el repositorio y ejecuta el script localmente.

01

Clona el repositorio

Descarga NeoComposer desde GitHub.

bash terminal
git clone https://github.com/4DRIAN0RTIZ/NeoComposer.git
cd NeoComposer
02

Ejecuta el instalador

El script detecta Arch, Debian/Ubuntu o Fedora y se encarga del resto: dependencias del sistema, dependencias Python, y el symlink.

bash terminal
sudo chmod +x install_neocomposer.sh
./install_neocomposer.sh
ℹ️

Distros soportadas: Arch, Ubuntu/Debian/Mint/Kali, Fedora/CentOS/RHEL. El instalador instala yazi, neovim, jq y python3 si no están presentes.

03

Configura tus credenciales

Edita el archivo .env que el instalador copió a ~/.config/neocomposer/.env.

env ~/.config/neocomposer/.env
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SENDER_EMAIL=tu@email.com
SENDER_PASSWORD=tu_app_password
SENDER_NAME=Tu Nombre
// configuración

SMTP y Gmail

Instrucciones para conectar NeoComposer con Gmail usando contraseña de aplicación.

⚠️

Gmail requiere contraseña de aplicación, no tu contraseña normal. Activa la verificación en dos pasos primero, luego ve a Cuenta de Google → Seguridad → Contraseñas de aplicación.

1

Activa IMAP en Gmail

En Gmail → Configuración → Ver toda la configuración → Reenvío y correo POP/IMAP → Habilitar IMAP.

2

Genera contraseña de aplicación

Google Account → Seguridad → Contraseñas de aplicación → Selecciona "Otra" → genera y copia la clave de 16 caracteres.

3

Configura el .env

env Gmail example
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SENDER_EMAIL=tucuenta@gmail.com
SENDER_PASSWORD=abcd efgh ijkl mnop # 16 chars, sin espacios
SENDER_NAME=Tu Nombre

Firma HTML (opcional)

Crea ~/.config/NeoComposer/signature.html con tu firma. Se añade automáticamente a cada correo.

html ~/.config/NeoComposer/signature.html

Flujo de trabajo interactivo

NeoComposer guía el proceso paso a paso.

Comando Descripción
neocomposer Inicia el compositor de correo
neocomposer --agenda Abre la gestión de agenda de contactos

Paso a paso al ejecutar 'neocomposer'

1

Elige destinatario

Ingresa un correo de uso único o selecciona uno de tu agenda.

2

Escribe el asunto

Texto libre en la terminal.

3

Redacta en Neovim

Se abre un buffer temporal. Escribe con todos los poderes de Neovim. Al guardar y salir (:wq) continúa el flujo.

4

Adjuntos opcionales

Si confirmas con S, se abre Yazi para navegar y seleccionar archivos. Puedes adjuntar múltiples.

5

Envío automático

NeoComposer conecta al SMTP, añade la firma HTML si existe, y envía. El archivo temporal se elimina.

// programmatic mode

Usage in scripts and automation

Integrate NeoComposer in your workflows with CLI arguments. Perfect for notifications, automated reports, and CI/CD.

Examples

bash Email simple
neocomposer \
  --recipient admin@dominio.com \
  --subject "Backup completado" \
  --body "El backup de hoy se completó exitosamente"
bash Con múltiples adjuntos
neocomposer \
  -r equipo@dominio.com \
  -s "Reporte de logs" \
  -b "Adjunto logs del sistema" \
  -a /var/log/syslog /var/log/auth.log
bash Cuerpo desde archivo
neocomposer \
  --recipient "cliente@ejemplo.com" \
  --subject "Reporte mensual" \
  --body-file /tmp/reporte.html
bash Usando contacto de agenda
neocomposer \
  --agenda-index 1 \
  --subject "Notificación automática" \
  --body "Este es un mensaje automatizado"
bash Integración en script de monitoreo
#!/bin/bash
DISCO=$(df -h / | awk 'NR==2 {print $5}' | sed 's/%//')
echo "Uso de disco: ${DISCO}%"

if [ "$DISCO" -gt 80 ]; then
  neocomposer \
    -r "admin@dominio.com" \
    -s "ALERTA: Disco al ${DISCO}%" \
    -b "El servidor necesita atención urgente"
fi

Programmatic script (examples)

Integrate NeoComposer in bash scripts to automate sends from cron, monitoring, or CI/CD.

📜 View programmatic examples (bash)
# Ejemplo
01 Simple email with recipient, subject, and direct body
02 Email with attachment
03 Multiple attachments and body from file
04 Using agenda contact by index
05 List agenda contacts
06 Send command output (e.g. df -h) by email
▶ Example 1: Simple email
#!/bin/bash
python main.py \
  --recipient "ejemplo@dominio.com" \
  --subject "Reporte de backup" \
  --body "El backup se completó exitosamente"
▶ Example 2: Email with attachment
python main.py \
  --recipient "admin@dominio.com" \
  --subject "Logs del sistema" \
  --body "Adjunto los logs del día de hoy" \
  --attachments "/var/log/syslog"
▶ Example 3: Multiple attachments and body from file
python main.py \
  --recipient "equipo@dominio.com" \
  --subject "Reporte mensual" \
  --body-file /tmp/body.txt \
  --attachments "/tmp/reporte.pdf" "/tmp/graficos.png"
▶ Example 4: Using agenda contact (index 1)
python main.py \
  --agenda-index 1 \
  --subject "Contacto desde agenda" \
  --body "Este email fue enviado usando el contacto de la agenda"
▶ Example 5: List agenda contacts
python main.py --list-contacts
▶ Example 6: Send command output by email
#!/bin/bash
DF_OUTPUT=$(df -h)
python main.py \
  --recipient "monitor@dominio.com" \
  --subject "Uso de disco" \
  --body "$DF_OUTPUT"

Opciones disponibles

Flag Descripción
--recipient, -r Recipient email (required if not using --agenda-index)
--subject, -s Email subject
--body, -b Message body (direct text)
--body-file, -f File with message body
--attachments, -a Files to attach (space separated, multiple)
--agenda-index, -i Contact index in agenda (1-indexed)
--list-contacts, -l List agenda contacts and exit
--interactive, -I Interactive mode (default if no other args passed)
--agenda Open contact agenda management
--help, -h Show full help
// agenda

Contact management

The agenda is a JSON at ~/.config/neocomposer/agenda.json. The agenda.sh script manages it interactively.

json agenda.json
{
  "contactos": [
    {
      "nombre": "Ada Lovelace",
      "correo": "ada@example.com"
    },
    {
      "nombre": "Linus Torvalds",
      "correo": "linus@linux.org"
    }
  ]
}
💡

Run neocomposer --agenda to manage contacts without editing the JSON manually. You can add, modify, and delete from the interactive menu.
